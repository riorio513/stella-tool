# 筆灯（ふでび） — 小説家の交流サイト 試作版

小説家どうしが交流できる、シンプルなWebサイトの試作版です。
`novel-community.html` を **ダブルクリックで開く** だけで、iPhone・Android・PC のどのブラウザでも動きます。

## できること

- **アカウント登録（メールアドレス必須）** … 登録した人だけが投稿・コメントできます
- **交流（SNS）** … 「執筆の妨げにならず、孤独を癒す」ための最小限の交流
  - **200文字までの投稿**（100文字以降は折りたたみ、「全文表示」で開く）
  - **投稿先をかならず選んでから投稿**（フォロワーのみ／誰もが見える／自分だけ）。設定は投稿ごとに保持されます
  - **「自分だけ」** … 誰にも見えない、自分用のメモとして書けます
  - 反応は3つだけ … **灯をともす**（“いいね”の代わり。数や順位は出ません）・**コメント**（200字）・**ブックマーク**
  - 初期表示は **フォロー中**、上部で **全体** へ切替
  - **検索**（ことばで投稿をさがす）・**ブックマーク一覧**（タップで該当投稿へ移動）
- **フォロー / フォロワー** … 気になる人をフォロー、相手のプロフィールから関係を管理
- **公開プロフィール** … 名前をタップでその人のプロフィール（自己紹介・好きなジャンル・URL）を表示
- **ブログ** … 管理人や認定された「ブロガー」が記事を書き、みんながコメントできます
- **通知（ベル）** … 灯をともされた・コメント・フォローされたお知らせ（数を伴わない、やさしい通知）
- **ホーム画面** … 左上の「筆灯」でいつでもホームへ。右上のアイコンで設定へ。「交流 / ブログ / 設定」へワンタップ移動
- **設定（ページ遷移式）**
  - 登録内容確認（メール確認・変更、サブスク案内）
  - プロフィール設定（ペンネーム・自己紹介・好きなジャンル＝タグ選択・URL置き場・フォロー/フォロワー一覧）
  - セキュリティ設定（パスワード変更・退会）
  - 交流設定（ブロック一覧・ミュートワード）
  - ブログ設定（コメント受付ON/OFF・自分の記事の編集削除）
  - データ（バックアップ・復元）
  - その他（規約・プライバシー・**お問い合わせ＝管理人へ意見を送信**・バージョン）
  - 管理人メニュー（管理人のみ：**ユーザー管理＝ブロガー認定／BAN**・**ユーザーからの声**・通報一覧）
- **ブロック / ミュートワード / 通報 / BAN** … 安心して使えるコミュニティ機能
- **デザイン** … レトロな書庫と文豪の趣を漂わせるアースカラー（古紙のベージュ＋濃い茶のインク）で、目にやさしい単一テーマ

## 使い方

1. `novel-community.html` をブラウザで開く
2. 「新規登録」からペンネーム・メールアドレス・パスワードで登録
   - **最初に登録した人が「管理人」になります**
3. 管理人は「設定 → 管理人メニュー → ユーザー管理」から、メンバーを
   **ブロガー認定**（記事執筆を許可）したり、**BAN**（強制退会・同じメールでの再登録を禁止）できます
4. 利用者の声は「設定 → その他 → お問い合わせ」から送信でき、**管理人だけ**が
   「管理人メニュー → ユーザーからの声」で、日時・送信者つきのログを確認できます

## ⚠️ 試作版についての注意

- データは**この端末のブラウザ内だけ**に保存されます。別の端末とは共有されません。
- ブラウザのデータを消すと内容も消えます。「設定 → データ → エクスポート」で定期的にバックアップを。
- パスワードを忘れたときの**メールでの再設定**は、本番版（クラウド）で対応予定です。試作版ではログイン後に「設定 → セキュリティ設定」からパスワードを変更できます。
- BANやお問い合わせのログも、この端末内にのみ保存されます（管理人の端末で確認してください）。

## 本番運用へ進むには

「どの端末からもログインして同じ投稿を見る」を本当に実現するには、
クラウド（Firebase / Supabase など）でアカウントとデータを管理する必要があります。
この試作版の画面・操作感をそのままに、保存先だけをクラウドへ差し替える形で発展させられます。
