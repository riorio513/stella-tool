# 筆灯（ふでび） — 小説家の交流サイト 試作版

小説家どうしが交流できる、シンプルなWebサイトの試作版です。
`novel-community.html` を **ダブルクリックで開く** だけで、iPhone・Android・PC のどのブラウザでも動きます。

## できること

- **アカウント登録（メールアドレス必須）** … 登録した人だけが投稿・コメントできます
- **交流（SNS）** … つぶやきを投稿、いいね・コメントでメンバー同士が交流
- **ブログ** … 管理人や招待された執筆者が記事を書き、みんながコメントできます
- **ホーム画面** … 「交流 / ブログ / 設定」へワンタップで移動
- **設定** … プロフィール編集、ダーク／ライト切替、データのバックアップ

## 使い方

1. `novel-community.html` をブラウザで開く
2. 「新規登録」からメールアドレスとパスワードで登録
   - **最初に登録した人が「管理人」になります**
3. 管理人は「設定 → 管理人メニュー」から、登録済みメンバーを **執筆者** に招待できます
   （招待するには、相手が先に登録を済ませている必要があります）

## ⚠️ 試作版についての注意

この版は**データをその端末のブラウザ内にだけ保存**します。そのため、

- 別の端末（スマホとPCなど）ではアカウントや投稿は共有されません
- ブラウザのデータを消すと内容も消えます

万一に備え、「設定 → データ → エクスポート」で定期的にバックアップしてください。
別ファイルを「インポート」すると復元できます。

## 本番運用へ進むには

「どの端末からもログインして同じ投稿を見る」を本当に実現するには、
クラウド（Firebase / Supabase など）でアカウントとデータを管理する必要があります。
その段階に進みたくなったら、この試作版の画面・操作感をそのままに、保存先だけを
クラウドへ差し替える形で発展させられます。
