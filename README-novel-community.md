# 筆灯（ふでび） — 小説家の交流サイト 試作版

小説家どうしが交流できる、シンプルなWebサイトの試作版です。
`novel-community.html` を **ダブルクリックで開く** だけで、iPhone・Android・PC のどのブラウザでも動きます。

## できること

- **アカウント登録（メールアドレス必須）** … 登録した人だけが投稿・コメントできます
- **交流（SNS）** … つぶやき投稿、いいね・コメント、「すべて／フォロー中」の切替
- **フォロー / フォロワー** … 気になる人をフォロー、相手のプロフィールから関係を管理
- **公開プロフィール** … 名前をタップでその人のプロフィール（自己紹介・好きなジャンル・URL）を表示
- **ブログ** … 管理人や招待された執筆者が記事を書き、みんながコメントできます
- **通知（ベル）** … いいね・コメント・フォローされたお知らせ
- **ホーム画面** … 「交流 / ブログ / 設定」へワンタップで移動
- **設定（ページ遷移式）**
  - 登録内容確認（メール確認・変更、サブスク案内）
  - プロフィール設定（ペンネーム・自己紹介・好きなジャンル＝タグ選択・URL・フォロー/フォロワー一覧）
  - セキュリティ設定（パスワード変更・退会）
  - 交流設定（ブロック一覧・ミュートワード）
  - ブログ設定（コメント受付ON/OFF・自分の記事の編集削除）
  - 表示設定（ダーク／ライト）
  - データ（バックアップ・復元）
  - その他（規約・プライバシー・お問い合わせ・バージョン）
  - 管理人メニュー（管理人のみ：執筆者招待・メンバー管理・通報一覧）
- **ブロック / ミュートワード / 通報** … 安心して使えるコミュニティ機能

## 使い方

1. `novel-community.html` をブラウザで開く
2. 「新規登録」からペンネーム・メールアドレス・パスワードで登録
   - **最初に登録した人が「管理人」になります**
3. 管理人は「設定 → 管理人メニュー」から、登録済みメンバーを **執筆者** に招待できます
   （招待するには、相手が先に登録を済ませている必要があります）

## ⚠️ 試作版についての注意

- データは**この端末のブラウザ内だけ**に保存されます。別の端末とは共有されません。
- ブラウザのデータを消すと内容も消えます。「設定 → データ → エクスポート」で定期的にバックアップを。
- パスワードを忘れたときの**メールでの再設定**は、本番版（クラウド）で対応予定です。試作版ではログイン後に「設定 → セキュリティ設定」からパスワードを変更できます。

## 本番運用へ進むには

「どの端末からもログインして同じ投稿を見る」を本当に実現するには、
クラウド（Firebase / Supabase など）でアカウントとデータを管理する必要があります。
この試作版の画面・操作感をそのままに、保存先だけをクラウドへ差し替える形で発展させられます。
